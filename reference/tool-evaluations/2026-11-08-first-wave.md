# First-wave tool evaluation — 2026-11-08

Контекст: **Maoris Digital Lab / KI-Lego**, а не NS Reinigungsdienst.
В этом отчёте «источник проверен» означает чтение официального README и метаданных GitHub, **не установленную и протестированную интеграцию**.

## Почему runtime не заявлен как пройденный

Текущее исполнительное окружение содержит Python, git и uv, **но не содержит Docker CLI**. Доступ к рабочим контейнерам Hetzner/n8n в этой задаче не подтверждён. Платные API, продакшн-сайты и реальные документы не использовались. Не считать результаты установки, скорости или точности измеренными.

## Приёмка для каждого инструмента

1. Создать отдельное тестовое окружение, зафиксировать релиз и checksum/commit. **Никаких изменений рабочего n8n**.
2. Поставить только необходимые компоненты, выполнить smoke-test из `integrations/<tool>/README.md`.
3. Зафиксировать команды, выходные данные, ошибки, CPU/RAM, время, сетевые обращения и операционные расходы.
4. Проверить безопасность: секреты через переменные окружения, доступ только к тестовым учётным записям и данным, не публиковать панели управления.
5. Принять решение: `approved`, `rejected`, либо `hold` с обоснованием. После `approved` — отдельное подключение к n8n / проекту.
6. Подтвердить право использования и обязательства по лицензии перед коммерческой поставкой.
