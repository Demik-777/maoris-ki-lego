# Maoris KI-Lego — open-source tools shortlist

> Дата снимка: **2026-11-08**. Источник метаданных: GitHub REST repository API. Звёзды и лицензии изменяются; перепроверяйте перед новым решением.
> Направление: **Maoris Digital Lab** и общая AI-инфраструктура. Этот каталог не смешивает документы или бизнес-правила с NS Reinigungsdienst.
> **Важно:** ссылки ниже не являются установленными инструментами, работающими сервисами или автоматически подключёнными скиллами.

## Правила отбора

1. Первичная отсечка — **не менее 20 000 звёзд GitHub** на дату проверки; это сигнал популярности, не гарантия безопасности или качества.
2. Оценивать соответствие стеку: **Claude Code / ChatGPT / n8n / Telegram / Hetzner / Google Sheets**, стоимость, зависимость от API, эксплуатационную нагрузку.
3. Предпочитать повторное использование официального upstream. **Форк — только когда требуется менять код**; иначе хранить ссылки, закреплённые версии и свои тонкие адаптеры.
4. Перед установкой: проверить релиз, лицензию, security advisories, примеры конфигурации, требования к RAM/CPU, сетевые доступы и обратимость изменений.
5. Запрещено автоматически выкатывать каталог на существующий сервер, выдавать доступ к Gmail/банку/клиентским данным или подставлять секреты в файлы.
6. Для простых задач не подключать дополнительные агенты и платформы ради числа инструментов.

## Маршрутизация по потребности

- **Сервис внезапно недоступен, нет алертов?** [Uptime Kuma](../integrations/uptime-kuma/README.md).
- **Нужно понимать сложные PDF, сканы и таблицы?** [Docling](../integrations/docling/README.md); для простых текстовых документов сначала оценить MarkItDown.
- **Нужно пройти пользовательский сценарий в браузере?** [Browser Use](../integrations/browser-use/README.md) в изолированном тестовом профиле; без финансовых и клиентских кабинетов.
- **Нужно структурировано извлечь публичный контент с сайта?** [Crawl4AI](../integrations/crawl4ai/README.md); уважать robots.txt, условия сайта и лимиты запросов.
- **Нужна методология новых AI-разработок?** сначала существующие `AGENTS.md`, локальные скиллы и [каталог проектов](project-tools.md); Superpowers добавлять выборочно.
- **Нужна база/деплой/аналитика?** только при подтверждённом требовании, не дублировать n8n и существующие инфраструктурные сервисы.

## Правило актуализации

При новом проекте сверить официальный README, LICENSE, релизы и звездность соответствующего upstream, проверить пересечения с локальным каталогом и выбрать **не более 1–3 реально полезных инструментов**. Не выдавать README за результат исполнения, а звёзды за аудит безопасности.
