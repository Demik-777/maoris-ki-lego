# Автоматический подбор KI-Lego в новых чатах

Одна актуальная точка входа: https://github.com/Demik-777/maoris-ki-lego/blob/master/AGENTS.md .
Универсальный порядок сборки: [task-assembly.md](task-assembly.md). Подходит любому проекту и формату результата; предметные маршруты — только примеры.
Каталог внешних проектов: [project-tools.md](project-tools.md).

## Готовая постоянная инструкция

Добавить к существующим инструкциям, не заменяя остальные правила:

```text
Перед выполнением новой задачи оцени необходимость Maoris KI-Lego (KaLego) по её реальной сложности, не загружая скилл для самой оценки. Не запускай KI-Lego для одношаговых запросов и задач с очевидным подходящим инструментом или профильным скиллом: поиск товаров и расходников, OCR/распознавание маркировки, перевод, короткое письмо, фактический ответ. Сам по себе бизнес-контекст NS/MDL, длина запроса или число вызовов инструментов не требуют KI-Lego. Вызывай KI-Lego только по прямой просьбе пользователя либо для архитектуры, разработки продуктов и агентов, автоматизаций, межсервисных интеграций, проектирования повторяемых процессов или выбора/координации нескольких готовых компонентов. Если KI-Lego нужен, обращайся к https://github.com/Demik-777/maoris-ki-lego и уже видимым возможностям: выбирай минимальную сборку, читай только релевантные инструкции и зависимости, не обходи весь каталог или GitHub без конкретной необходимости, не устанавливай лишнее и выполняй задачу до проверяемого результата. При продолжении переиспользуй сборку. Разделяй NS Reinigungsdienst и Maoris Digital Lab; проверяй фактический статус сервисов и разрешения на внешние изменения.
```

## Где размещать

- ChatGPT: пользовательские инструкции в настройках персонализации — правило для работы в разных чатах. Для важных проектов добавить также в инструкции проекта, чтобы правило было явно задано в его контексте.
- Codex: глобальный `~/.codex/AGENTS.md` для разных репозиториев или `AGENTS.md` в корне конкретного рабочего проекта. Если задан иной CODEX_HOME, использовать его. Наличие `AGENTS.override.md` может менять применяемый файл.
- Другие ассистенты: постоянные пользовательские или проектные инструкции соответствующей среды. Сам GitHub-репозиторий не изменяет их настройки.
- Личный скилл maoris-ki-lego разрешён для автоматического применения в поддерживающей среде. Постоянная инструкция закрепляет ожидаемое поведение; она уже может быть задана пользователем. Обновление исходных инструкций не обновляет автоматически установленную копию; проверять выпуск по reference/ki-lego-release.json.

Нужен доступ к GitHub через коннектор или публичное веб-чтение. Если доступа нет, ассистент сообщает об ограничении. Постоянная инструкция задаёт ожидаемое поведение, но не является программным перехватчиком каждого чата и не гарантирует загрузку URL в любой среде.

## Накопление опыта

Частный журнал опыта поддерживается установленным скиллом по references/learning.md. При запуске scripts/route.py search возвращает только относящиеся к запросу наблюдения; они не заменяют правила текущего проекта и проверку доступа. Устаревшие записи можно снять, заменить или исключить из выдачи по сроку пересмотра; историю сохранять. Записи нужно сохранять штатным способом личных скиллов. Копировать сырой чат, секреты и частный журнал в публичные исходники нельзя.

## Проверка в новом чате

Проверить два контрастных сценария: «Найди мешки для Kärcher NT 22/1 на Amazon» (KI-Lego НЕ загружается) и «Спроектируй Telegram-приложение с n8n для обработки документов» (KI-Lego загружается).

Ожидаемый результат: первый запрос идёт напрямую через поиск товаров; во втором ассистент обращается к KI-Lego и выбирает минимальную полезную сборку. Это сценарные проверки, а не гарантия срабатывания во всех чатах. Попросить указать прочитанные пути и commit, если нужно проверить доступ.
