# Автоматический подбор KI-Lego в новых чатах

Одна актуальная точка входа: https://github.com/Demik-777/maoris-ki-lego/blob/master/AGENTS.md .
Каталог внешних проектов: [project-tools.md](project-tools.md).

## Готовая постоянная инструкция

Добавить к существующим инструкциям, не заменяя остальные правила:

```text
В начале каждой новой содержательной задачи автоматически проверяй Maoris KI-Lego: https://github.com/Demik-777/maoris-ki-lego . Прочитай AGENTS.md, затем reference/project-tools.md и подходящие материалы каталога. Учитывай также наши форки LLM Council (Карпати, консилиум) и AutoGen по условиям в каталоге. Выбирай обычно 1–3 полезных материала, кратко объясняй их пользу и продолжай работу без напоминания с моей стороны. Разделяй NS Reinigungsdienst и Maoris Digital Lab. Не перечитывай неизменённые материалы в рамках одной задачи; простые переводы и короткие уточнения пропускай. Различай применение методики и реальный запуск программы или нескольких моделей. Если GitHub недоступен, прямо сообщи об этом и продолжай доступную часть работы.
```

## Где размещать

- ChatGPT: пользовательские инструкции в настройках персонализации — правило для работы в разных чатах. Для важных проектов добавить также в инструкции проекта, чтобы правило было явно задано в его контексте.
- Codex: глобальный `~/.codex/AGENTS.md` для разных репозиториев или `AGENTS.md` в корне конкретного рабочего проекта. Если задан иной CODEX_HOME, использовать его. Наличие `AGENTS.override.md` может менять применяемый файл.
- Другие ассистенты: постоянные пользовательские или проектные инструкции соответствующей среды. Сам GitHub-репозиторий не изменяет их настройки.
- Личный скилл maoris-ki-lego может помогать подбору, но не заменяет постоянную инструкцию в среде нового чата. Обновление репозитория не обновляет автоматически установленный скилл.

Нужен доступ к GitHub через коннектор или публичное веб-чтение. Если доступа нет, ассистент сообщает об ограничении. Постоянная инструкция задаёт ожидаемое поведение, но не является программным перехватчиком каждого чата и не гарантирует загрузку URL в любой среде.

## Проверка в новом чате

Начать с обычной рабочей задачи, например: «Помоги выбрать архитектуру Telegram-приложения для обработки документов».

Ожидаемый результат: ассистент сам обращается к KI-Lego, выбирает полезные материалы, оценивает применимость Council/AutoGen и объясняет выбор без притворного запуска сервисов. Попросить указать прочитанные пути и commit, если нужно проверить доступ.
