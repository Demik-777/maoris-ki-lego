# Browser Use — изолированное тестирование интерфейса MDL

- Upstream: https://github.com/browser-use/browser-use
- Source license according to GitHub API (2026-11-08): MIT; stars: 120 288.
- Назначение: автоматизированно проходить E2E-сценарии тестовых веб-приложений.
- Статус: **README reviewed, not installed / not run**.

## Правила безопасности

Только отдельный браузерный профиль и тестовый сайт/стенд. Никаких приватных cookie, банковских/Google/WordPress учётных записей или производственной клиентской информации. Перед работой зафиксировать версию пакета и требуемую модель; облачный сервис/API может быть платным.

## Первичный smoke test (без реальных аккаунтов)

```bash
python -m venv .venv-browser-use
. .venv-browser-use/bin/activate
python -m pip install --upgrade pip
python -m pip install browser-use
python -c "import browser_use; print('import OK')"
```

Для полноценного агента по инструкции upstream потребуются браузерная инфраструктура и настроенный LLM provider. Сам импорт не означает, что агент запускается.

## E2E тест после настройки

1. Поднять локальный фиктивный веб-сайт с двумя страницами, формой и кнопкой.
2. Поручить агенту пройти 3 шага, записать действия и конечный результат.
3. Измерить успешность по 10 повторениям, время, число токенов/стоимость.
4. Попробовать сломанную кнопку, редирект и таймаут; исключить бесконечные циклы.
5. Проверить, что агент не выходит за allowlist локальных URL и не читает секреты.

PASS = высокая воспроизводимость тестового сценария с контролируемыми действиями/расходами и доказанной изоляцией. **Не выполнено**.
