# Crawl4AI — тест публичного web extraction

- Upstream: https://github.com/unclecode/crawl4ai
- Source license according to GitHub API (2026-11-08): Apache-2.0; stars: 87 074.
- Назначение: публичные сайты → нормализованный Markdown / JSON → downstream n8n.
- Статус: **README reviewed, not installed / not run**. Self-host и Cloud — разные способы использования.

## Безопасный начальный тест

Только тестовые страницы или публичные сайты с разрешённым сканированием. Соблюдать robots.txt, условия использования, разумные таймауты и частоту. Для тестов с персональными данными / cookies нужна отдельная оценка.

```bash
python -m venv .venv-crawl4ai
. .venv-crawl4ai/bin/activate
python -m pip install --upgrade pip
python -m pip install crawl4ai
python -c "import crawl4ai; print('import OK')"
```

Для полноценного запуска потребуются браузерные зависимости согласно текущей инструкции upstream; возможна установка Chromium. В отсутствие такого окружения только import test.

## Тест-кейсы

1. Статическая локальная страница: заголовок, ссылки, таблица.
2. Динамическая тестовая страница (JavaScript).
3. Страница с медленным ответом и ошибкой 429 — проверить таймаут/повтор.
4. Вывод Markdown/JSON: сравнить с эталоном, исключить рекламу/навигационный шум.
5. Записать время, CPU/RAM, объём выдачи, пропуски и ограничения источника.

PASS = извлечены основные поля, нет лишних запросов или непредсказуемых ошибок, данные годятся для дальнейшей структурной обработки. **Не выполнено**.
