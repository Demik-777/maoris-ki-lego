# Maoris KI-Lego

Открытое рабочее хранилище для любой LLM-модели или AI-ассистента с доступом к репозиторию.

Общие правила навигации и применения материалов — в [AGENTS.md](AGENTS.md), описание структуры — в [README.md](README.md).

Файлы и настройки в формате Claude Code сохранены для совместимости с этой средой. Другие модели могут читать и адаптировать материалы к своим инструментам.
