# Короткая запись проекта

Использовать существующий формат проекта. Если его нет — компактный текст:

- **Цель и сейчас:** какой результат нужен и где остановились.
- **Решили:** только явные решения пользователя и их основания.
- **Идеи:** варианты для последующего рассмотрения; не выдавать за план.
- **Открыто:** что требует проверки или решения.
- **Сделано и проверено:** конкретный результат, ссылка, реально выполненная проверка.
- **Следующее действие:** один выполнимый шаг; ответственный и дата только если согласованы.
- **Источники:** ссылки/пути и даты нужных материалов; границы полноты.

Пустые разделы опускать. Для одной идеи хватит нескольких предложений. Отдельный документ на каждый короткий ответ не создавать.

Для значимого изменения сохранить, какое прежнее решение оно заменяет и на каком основании. Завершённое отмечать, а не удалять историю. Если обновление записи не удалось, выдать полезный текст для переноса и прямо сказать, что сохранение не подтверждено.

Пример различения: «Решено: хранение пока 24 часа. Идея: голосовой ввод. Открыто: тариф. Поздний вариант: рассмотреть 7 дней; действующий срок ещё не изменён».
