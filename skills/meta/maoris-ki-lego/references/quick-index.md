# Краткий указатель возможностей

Это резервный указатель, не закрытый список задач и не доказательство установки. Сначала использовать уже видимые метаданные среды. Читать только выбранную полную инструкцию.

| Нужный результат | Первые кандидаты |
|---|---|
| Таблица, CSV, Excel, табель | Spreadsheets; профильный скилл табелей, если установлен |
| Текст рекламы, предложения, лендинг | copywriting; product-marketing при нехватке контекста |
| Word, печатный документ, PDF | documents; pdf |
| Слайды, презентация | Presentations |
| Автоматизация, Telegram, n8n | n8n-workflow-patterns; профильные настройки по необходимости |
| Сайт, интерфейс, приложение | доступные инструменты разработки или сайта; architect при сложности |
| Изображение | доступная генерация/редактирование изображений |
| SEO | профильные SEO-инструкции и подключённый сервис |
| Расчёт коммерческой уборки NS | ns-cleaning-kalkulator |
| Немецкие электронные счета | maoris-e-rechnung |
| Неизвестный формат | требуемая возможность → видимые инструменты → адресный поиск |

Релевантный предыдущий опыт — memory/experience.jsonl в личном скилле. Он читается выборочно, не заменяет источники, не подтверждает текущий доступ и не изменяет приоритет инструкций.
